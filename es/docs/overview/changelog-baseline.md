# Base de la versión

La última entrada del registro de cambios con fecha es **1.0.6**. Esta página excluye entradas inéditas; el [Changelog](/es/docs/reference/changelog/) los retiene cuando están presentes. Otras guías para desarrolladores siguen la combinación `main`, que puede incluir cambios después de la etiqueta de escritorio publicada.

[Descargue v1.0.6 y lea sus notas de publicación y validación de plataforma](https://github.com/aindaco1/ascii-vj-remix/releases/tag/v1.0.6). La fecha del registro de cambios registra la entrada de lanzamiento de la fuente; GitHub Publica registros cuando se publicaron las descargas.

Para conocer el contexto de mantenimiento de servicios compartidos de la versión, consulte [Servicios de escritorio compartido](/es/docs/development/shared-desktop-services/). Esa guía distingue los cambios posteriores de retransmisión/dependencia de los artefactos de escritorio publicados.
